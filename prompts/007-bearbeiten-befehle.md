# Prompt 007: Bearbeitungsbefehle

> Lies zuerst [000-arbeitsweise.md](000-arbeitsweise.md). Braucht: 003, 005. Legacy: §2, §8 (Todos).

## Umfang

- Zeilen sortieren auf-/absteigend (legacy Strg+Umschalt+Alt+A/D): natürlich (1, 2, 10), Groß/klein ignorieren,
  numerisch, Duplikate entfernen – für Auswahl oder ganzes Dokument, in Rust.
- Groß-/Kleinschreibung wechseln (legacy Strg+U), Zeile duplizieren, Zeile löschen, Zeilen verschieben, Zeilen
  verbinden, Ein-/Ausrücken der Auswahl, Leerzeichen am Zeilenende entfernen, Tabs ↔ Leerzeichen.
- Blockauswahl (Alt+Ziehen / Alt+Umschalt+Pfeile, legacy „Column Mode“ inkl. Breite 0 zum Einfügen).
- Marker (legacy „Mark Text“ Strg+Umschalt+F7, „Clear All Markers“ Strg+Umschalt+F8): Vorkommen des Wortes farbig
  markieren, mehrere Farben, alle löschen.
