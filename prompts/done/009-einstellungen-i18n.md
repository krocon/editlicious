# Prompt 009: Einstellungen und Sprache

> Lies zuerst [000-arbeitsweise.md](000-arbeitsweise.md). Braucht: 005. Legacy: §5 (Options).

## Umfang

- `settings.json` im App-Config-Ordner (atomar, nachsichtig laden), Einstellungsdialog (Mod+,).
- Schrift (Monospace-Auswahl), Größe + Zoom (Mod+Plus/Minus/0, legacy Strg+Num+/−, Strg+F9), Tabweite (2/4/6/8,
  legacy), Tabs oder Leerzeichen, Zeilennummern (aus/absolut/relativ), Einrückungslinien (legacy Strg+Alt+L),
  aktuelle Zeile hervorheben, Umbruch, Theme folgen/hell/dunkel, Fragen beim Schließen/Beenden, letzte Dateien laden.
- Deutsch/Englisch zur Laufzeit (Textkataloge), Standard nach System.
